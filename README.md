# 180 Days → ML Engineering

> Learning → Building → Breaking → Fixing

This repository documents my 180-day journey toward becoming
an ML Engineer.

I'm an IT graduate transitioning into Machine Learning Engineering
and using this repository to document what I learn, the experiments
I run, the problems I encounter, and the projects I build.

This is not a collection of copied tutorials.

The goal is to build real understanding through practice.

---

## 🎯 The Goal

By the end of these 180 days, I want to be capable of:

- Working confidently with Python and data
- Building and evaluating machine learning models
- Understanding the fundamentals of deep learning
- Building ML APIs
- Containerizing ML applications
- Tracking ML experiments
- Designing production-oriented ML systems
- Building a strong portfolio
- Applying for junior ML/AI engineering opportunities
